# Planning perso

Application personnelle de planning (calendrier, tâches, notes, courrier et agenda Google).

## Structure
- `index.html` : la page (interface complète, sans dépendance serveur pour le moment).
- `supabase/` : base de données et fonctions serveur (à venir).
